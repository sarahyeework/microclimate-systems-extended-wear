# Microclimate Systems for Extended Wear

This project explores extended-wear textile systems for space medicine and extreme environments.

## Problem
On long-duration missions, clothing becomes a consumable because garments cannot be laundered easily. Frequent replacement increases mass, waste, and resupply burden.

## Solution
We designed a merino-based sock system with:
- moisture regulation
- odor resistance
- targeted compression
- optional silicone grip for microgravity stability

## Study Design
We designed a randomized within-subject crossover study comparing baseline socks with an optimized sock system under 24–48 hour wear intervals.

## Mission Impact Model
This repository includes a simple Python model estimating how extended sock wear intervals affect:
- total sock pairs required
- total clothing mass
- replacement reduction over a 180-day mission

## Example Assumptions
- crew size = 6
- mission duration = 180 days
- baseline replacement = 1 pair/day
- optimized replacement = 1 pair/3 days
- sock mass = 0.06 kg/pair

## Earth Applications
This system also has relevance for:
- firefighters
- field operators
- accessibility-constrained users
- people with balance or circulation concerns
